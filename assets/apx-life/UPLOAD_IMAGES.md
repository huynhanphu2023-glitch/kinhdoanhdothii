# APX LIFE house image slots

Drop your own WebP images into the existing `properties` and `interiors` folders using these exact names. The game checks for the WebP first and falls back to the included SVG artwork when a slot is empty. No SQL change is needed when you use these names.

Use landscape 16:9 images, preferably 1280x720 or smaller and optimized for mobile. Keep the files project-owned or licensed for use. These static images are part of the game and are not player uploads.
